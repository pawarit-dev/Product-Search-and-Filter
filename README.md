# Product Search and Filter

A JavaScript project that demonstrates how to search and filter a product list.

## Features

- Filter products by category
- Filter products by maximum price
- Find a product by ID
- Search products by name
- Get products that are currently in stock

## Getting Started

Run the script with Node.js:

```bash
node productSearch.js
```

The script prints the results of each search and filter operation to the console.
